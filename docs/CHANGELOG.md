# 更新记录

## v1.6.6（2026-11-26）

- 支持单独绑定 `PrtSc`（#112），标注粗细新增明确的加减按钮（#110）。
- 自定义动作支持独立「等待」模块和单次无描边截图（#113），依赖运行支持自定义 FFmpeg 目录（#105）。
- 修复贴图调整填充透明度时的圆角浮条跳动，以及新增动作界面的悬停闪烁与模块选择问题。

## 2026-11-17（二）Google Drive 登录配置

- 官网和 GitHub 构建共用 Google Drive 登录入口。缺少桌面 OAuth 凭据时，可从设置页导入 Google Cloud 下载的 JSON。

## 2026-11-17（一）统一公开工作目录与发布入口

- 源码移至 `src`，根目录提供开发运行、编译发布、版本号和更新记录。开发版快捷方式指向 `dist/dev`。
- 公开 Release 入口从公开提交分别取得安装包和更新记录，运行组件仍按需下载。
